**Engine Version**: `0.1.0`  
**Evaluation Target**: Deterministic Monorepo Fixtures (`demo/before/*`, `demo/after/*`)

## 1. Textual Noise vs. Structural Signal Compression

The central value proposition of ISOMORPH is isolating true behavioral signal from large, noise-inflated text diffs.

| Metric | Scenario 01: Refactor Noise (`pricing/discount.js`) | Scenario 02: Tiny Mutation (`pagination/bounds.js`) | Scenario 03: Security Risk (`security/auth.js`) |
| :--- | :--- | :--- | :--- |
| **Raw Lines Changed** | **842 lines** (+482 / -360) | **3 lines** (+2 / -1) | **22 lines** (+12 / -10) |
| **CST Nodes Diffed** | 302 nodes | 12 nodes | 46 nodes |
| **Cosmetic Diffs Collapsed** | **839 diffs** (99.6%) | 0 diffs | 0 diffs |
| **Isolated Behavior Signals** | **3 mutations** (1 HIGH, 2 MED) | **1 mutation** (1 HIGH) | **3 mutations** (3 HIGH) |
| **Signal-to-Noise Ratio** | 3 / 842 lines (0.35%) | 1 / 3 lines (33.3%) | 3 / 22 lines (13.6%) |
| **Evidence Runner Outcome** | `FAIL (1/1 stubs)` | `FAIL (1/1 stubs)` | `FAIL (1/1 stubs)` |

### Analysis of Compression Results
- **Scenario 01 (Flagship Corpus)**: Demonstrates extreme noise reduction. 842 lines of diff generated by an AI refactor (reformatting, variable renames, statement movement) collapsed down to 3 behavioral changes. The critical logic mutation—removing a guard clause in `calculateDiscount`—was isolated with 100% precision.
- **Scenario 02 (Diff Size Invariance)**: Proves that ISOMORPH does not correlate "small diff" with "safe change". A 3-line simplification contained a fatal off-by-one boundary check (`index > totalPages` instead of `>= totalPages`), immediately flagged as `HIGH` risk.
- **Scenario 03 (Security Boundaries)**: Validates complete verification loop on authorization middleware, catching 3 high-risk security regressions: token expiry removal, permission degradation, and unauthenticated admin bypass.

## 4. Stated Boundaries & What Was NOT Benchmarked

In accordance with constitutional claim discipline:

1. **Not Benchmarked on Multi-Million-Line Monorepos**: The current MVP is designed for single-file before/after comparison. Full repository dependency graph indexing is future work.
2. **Not Claiming Semantic Equivalence**: CST hash identity proves structural syntax-node equivalence. It does not solve Rice's Theorem or prove universal semantic equivalence.
3. **No Unsubstantiated Time-Savings Claims**: We do not claim arbitrary review speedup percentages ("73% faster reviews") because review times depend on team-specific workflows and human factors. We measure and report only what our instrumentation directly computes.
